Two independent admin-UX fixes on the same admin surface.

Purpose: cut a five-step retype-and-remember chore down to two clicks and a location pick, and stop the admin header from looking broken.
Output: an Approve path proven end-to-end by Playwright, a single admin navigation bar, and no stale exact-list assertions left behind.

No database migration. No new API route. No new dependency.

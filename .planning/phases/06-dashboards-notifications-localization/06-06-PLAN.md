Purpose: NOTIF-01 through NOTIF-04 are the only phase requirements whose data already exists in production but has never been displayed. This plan is where "real-time in-app updates" in the roadmap goal becomes literally true.
Output: one generated shadcn primitive, one copy resolver, one client component owning a websocket lifecycle, and the header mount.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Realtime websocket → browser component state | Row payloads arrive outside the request/response cycle and outside any Route Handler's validation |
| dictionary value → rendered DOM | Translated strings become React children in the header on every page |
| header render → role decision | The role that gates the bell and picks the copy comes from the server-side profiles read, not from the client |

| T-06-26 | Elevation of Privilege | Realtime channel filter spoofing | high | mitigate | `notifications_select_own` re-authorizes every event server-side per subscriber regardless of the client-supplied filter string; the component additionally drops any payload whose `user_id` does not equal the signed-in user's id |

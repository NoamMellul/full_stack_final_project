## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser cookie jar → root layout render | An attacker-controlled cookie value flows directly into `<html lang>` and `<html dir>` unless it is allow-listed first |
| browser → `POST /api/locale` | Untrusted JSON body crosses here on an endpoint that deliberately requires no authentication |
| anonymous visitor → SiteHeader | The header now renders for logged-out visitors and must not reveal anything about session state beyond its presence |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-20 | Tampering | locale cookie flowing into `lang`/`dir` | high | mitigate | `readLocale()` validates against the fixed two-value allow-list and returns `"en"` for anything else, so an arbitrary cookie value can never reach an HTML attribute |
| T-06-21 | Tampering | `POST /api/locale` body | medium | mitigate | `validateLocaleInput()` rejects any value outside the allow-list with a 400 before `.set()` is reached; the handler writes exactly one cookie and never touches the session |
| T-06-22 | Information Disclosure | `components/site-header.tsx` rendering for anonymous visitors | medium | mitigate | The anonymous branch renders only the brand link and the switcher; the `profiles` lookup is skipped entirely when there is no user, so no profile field is fetched for an anonymous request |
